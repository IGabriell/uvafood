Quero que você transforme o meu site atual em uma experiência muito mais sofisticada, moderna, imersiva e profissional, mantendo a identidade visual e a proposta original do projeto, mas elevando drasticamente a qualidade do design, UX e interações.

NÃO quero apenas adicionar elementos decorativos. Quero que o site pareça um produto real, pronto para ser utilizado por usuários de verdade.

OBJETIVO PRINCIPAL:
Criar uma experiência visual premium, com animações suaves, navegação intuitiva, elementos interativos e sensação de profundidade. O usuário deve sentir vontade de explorar o site e continuar rolando a página.

1. EXPERIÊNCIA DE SCROLL E ANIMAÇÕES

Crie animações vinculadas ao scroll do mouse.

As animações devem acompanhar o progresso da página enquanto o usuário desce ou sobe, em vez de simplesmente aparecerem automaticamente.

Quero:
- Elementos entrando suavemente conforme aparecem na tela.
- Parallax em imagens e elementos de fundo.
- Cards com movimento sutil durante o scroll.
- Transições entre seções.
- Elementos que mudam de posição, escala ou opacidade conforme o usuário rola.
- Animações suaves e profissionais, sem exagero.
- Efeitos de profundidade.
- Microinterações ao passar o mouse.
- Transições de página e navegação sofisticadas.

IMPORTANTE:
As animações precisam melhorar a experiência e não prejudicar a usabilidade ou deixar o site lento.

2. PLANO DE FUNDO

Crie pelo menos um plano de fundo realmente sofisticado e visualmente marcante.

Não quero um fundo genérico com apenas um gradiente.

Utilize uma composição visual coerente com o tema do site, com:
- profundidade;
- iluminação;
- elementos sutis em movimento;
- partículas ou efeitos discretos quando fizer sentido;
- camadas de fundo;
- contraste suficiente para manter os textos legíveis.

O fundo deve dar sensação de produto premium, mas sem competir com o conteúdo.

3. MAPA REAL E LOCALIZAÇÃO DO USUÁRIO

Melhore completamente a seção de localização.

Não quero um mapa fictício ou apenas uma imagem parecida com um mapa.

Utilize uma abordagem de mapa real e funcional.

O usuário deve poder:
- permitir acesso à localização;
- visualizar sua localização atual;
- visualizar pontos próximos;
- encontrar estabelecimentos ou pontos relevantes próximos à sua posição;
- visualizar marcadores reais;
- interagir com o mapa;
- aproximar e afastar;
- movimentar o mapa.

Caso seja necessário utilizar uma API externa, deixe a estrutura preparada para integração com uma API de mapas real, como Mapbox ou Google Maps.

NÃO invente uma localização real do usuário.

A localização só deve ser utilizada depois que o usuário conceder permissão.

Se a permissão não for concedida, mostrar uma alternativa amigável para inserir a localização manualmente.

4. SISTEMA DE PRODUTOS

Expanda o catálogo atual.

Além dos produtos existentes, adicione uma estrutura mais completa de:
- bebidas;
- combos;
- acompanhamentos;
- promoções;
- produtos individuais;
- opções personalizáveis.

Crie cards de produtos mais sofisticados contendo:
- imagem;
- nome;
- descrição;
- preço;
- avaliações quando aplicável;
- botão de adicionar;
- opções de personalização;
- indicação de promoção quando houver.

Crie categorias bem organizadas para facilitar a navegação.

Exemplo:

Lanches
Combos
Bebidas
Acompanhamentos
Promoções

5. COMBOS

Crie uma seção específica de combos.

Os combos devem parecer realmente vantajosos e visualmente atraentes.

Exemplo de estrutura:

Combo
Produto principal + acompanhamento + bebida

Mostrar:
- produtos incluídos;
- preço individual estimado;
- preço do combo;
- economia;
- botão "Adicionar combo".

6. PLANNER / ÁREA DO USUÁRIO

Crie uma experiência muito mais completa para o usuário.

Quero uma área de usuário/planner que permita:

- criar perfil;
- visualizar pedidos;
- acompanhar pedidos;
- salvar produtos favoritos;
- criar pedidos personalizados;
- visualizar histórico;
- salvar endereços;
- definir localização;
- visualizar promoções personalizadas;
- repetir pedidos anteriores;
- gerenciar preferências.

Crie uma navegação clara e moderna para essa área.

7. CARRINHO

Melhore completamente o carrinho.

O usuário deve conseguir:
- adicionar produtos;
- alterar quantidade;
- remover produtos;
- personalizar itens;
- visualizar subtotal;
- visualizar descontos;
- visualizar taxa de entrega;
- visualizar total;
- aplicar cupom;
- escolher endereço;
- escolher forma de pagamento.

Crie uma experiência de checkout simples e intuitiva.

8. NAVEGAÇÃO

Crie uma navegação extremamente intuitiva.

O usuário deve conseguir acessar facilmente:

Home
Cardápio
Combos
Bebidas
Promoções
Mapa
Pedidos
Favoritos
Perfil
Carrinho

No desktop, utilize uma navbar elegante.

No mobile, utilize uma navegação inferior ou menu adaptado para telas pequenas.

A navegação deve acompanhar o usuário quando fizer sentido, mas sem ocupar espaço excessivo.

9. HOME PAGE

Transforme a Home em uma experiência visual impactante.

Hero section:
- título forte;
- subtítulo;
- CTA principal;
- imagem ou composição visual de alta qualidade;
- animação de entrada;
- fundo sofisticado.

Depois do Hero, apresentar progressivamente:

Categorias
Produtos em destaque
Combos
Promoções
Bebidas
Localização
Avaliações
Benefícios
CTA final

Use o scroll para criar uma narrativa visual.

10. MICROINTERAÇÕES

Adicione microinterações em praticamente todos os elementos interativos.

Exemplos:
- botões com hover;
- cards elevando suavemente;
- imagens com zoom discreto;
- ícones animados;
- feedback ao adicionar ao carrinho;
- contador de itens animado;
- transições suaves;
- estados de loading;
- estados vazios;
- mensagens de sucesso;
- mensagens de erro.

11. RESPONSIVIDADE

O site precisa funcionar perfeitamente em:

Desktop
Notebook
Tablet
Celular

Não simplesmente diminua os elementos.

Adapte a experiência para cada tamanho de tela.

12. ACESSIBILIDADE

Garanta:
- contraste adequado;
- textos legíveis;
- botões facilmente identificáveis;
- navegação por teclado quando aplicável;
- estados de foco;
- mensagens claras;
- respeito à preferência de redução de movimento quando possível.

13. PERFORMANCE

Apesar de todas as animações, o site deve continuar rápido.

Evite:
- animações exageradas;
- efeitos desnecessariamente pesados;
- excesso de partículas;
- elementos que causem travamentos;
- transições longas.

Priorize animações usando transform e opacity quando possível.

14. DESIGN SYSTEM

Crie uma identidade visual consistente.

Defina:
- cores;
- tipografia;
- espaçamentos;
- bordas;
- sombras;
- radius;
- botões;
- cards;
- inputs;
- ícones;
- estados de interação.

Tudo deve parecer parte do mesmo produto.

15. SENSAÇÃO FINAL

Quero que o resultado tenha aparência de uma startup/produto tecnológico real e premium.

Evite aparência de:
- template genérico;
- landing page simples;
- site escolar;
- dashboard sem personalidade;
- excesso de gradientes;
- excesso de glassmorphism;
- animações aleatórias.

Quero uma experiência moderna, sofisticada e memorável.

O usuário deve entrar no site e pensar:

"Isso parece um produto profissional de verdade."

IMPORTANTE:

Não remova funcionalidades que já existem.

Não substitua o projeto inteiro por uma página genérica.

Analise primeiro a estrutura atual e evolua o que já existe.

Mantenha os conteúdos e funcionalidades importantes e melhore sua apresentação, navegação e experiência.

Priorize UX real sobre efeitos visuais.

Sempre que adicionar uma funcionalidade que dependa de backend, API ou serviço externo, deixe claramente estruturada a interface e os estados necessários para uma futura implementação real.

O resultado final deve ser sofisticado, funcional, responsivo e visualmente surpreendente.
